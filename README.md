# CCAR-F Practice Exam

Unofficial practice questions for the Claude Certified Architect - Foundations (CCAR-F) exam.
150 original scenario-based questions in English, 30 per domain, with an explanation for every answer option.

- Practice mode: feedback and explanations after every question.
- Exam simulation: 60 questions drawn per domain, 120 minutes, flag and review, scored at the end.
- Progress is stored in the browser (localStorage) only.

**Not official Anthropic material.** The questions are written from public Anthropic documentation, not from the
confidential exam guide, and are not affiliated with or endorsed by Anthropic. Domain names and weights are
community-reported and unverified. Check details against the current Anthropic documentation.

## Run

Open `index.html` in a browser. No build step. Keep all files in the same folder.

## Files

- `index.html` - the app (HTML and CSS)
- `app.js` - practice and exam logic
- `d1.js` to `d5.js` - questions per domain
